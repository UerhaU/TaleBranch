# Подготовка первой беты

Версия: `0.1.0-beta.1`. Планируемый тег: `v0.1.0-beta.1`. Дата подготовки: 17 октября 2026 года.

**Статус: кандидат подготовлен локально; публичный релиз не создан.** Владелец сообщил, что новый portable ещё не проверял вручную. Результаты автотестов и headless-проверки `.exe` не выдаются за проверку настольного интерфейса.

## Что подготовлено

- README на русском и английском: запуск обычным двойным щелчком, отличие portable от исходников, отсутствие сервера, WebView2, расположение файлов, перенос данных из браузерной альфы и известные ограничения.
- Версия кандидата в `package.json`, lock-файлах, Tauri и интерфейсе.
- `CHANGELOG.md` и текст будущего релиза `docs/releases/v0.1.0-beta.1.md`.
- Скрипт сборки portable с тестами интерфейса и нативного хранения, проверкой собранного `.exe`, архивом и SHA-256.
- Ручная сборка Windows в GitHub Actions без установщика. Чистый клон может собираться без локального набора игровых иконок со стандартными значками.

## Ручная проверка перед публикацией

Распаковать кандидат в отдельную папку, например `D:\TaleBranch-beta-test`. Работать с отдельной тестовой династией, без изменения личных данных.

- [ ] Запустить `.exe` при закрытом браузере и без запущенного `npm run dev`. Должно открыться собственное окно TaleBranch.
- [ ] Создать династию: выбрать непустое место сохранения, указать название, убедиться, что появилась отдельная папка с `dynasty.json`, а соседние файлы остались.
- [ ] Добавить персонажа с фотографией, настроить кадр, выбрать возраст, черты, жизненную цель и карьеру. Убедиться, что текст и значки отображаются.
- [ ] Добавить питомца с хозяином; проверить, что без хозяина сохранить нового питомца нельзя.
- [ ] Создать родство и личное отношение. Проверить линии, метки и независимые фильтры.
- [ ] Дождаться статуса «Сохранено», закрыть программу, запустить заново и открыть династию из недавних. Проверить имя, фотографию, её кадрирование, связи и поля карточки.
- [ ] Экспортировать `.dynasty-tree` и PNG через системные окна сохранения. Открыть PNG. Импортировать экспорт в отдельное место и сравнить данные.
- [ ] В отдельной тестовой карточке проверить корзину, восстановление и безвозвратное удаление. Удалённая карточка не должна возвращаться после перезапуска и Ctrl+Z.

## Файлы будущего релиза

Из `release/portable` прикрепляются только файлы нужной версии:

- `TaleBranch-0.1.0-beta.1-portable.zip` — основной архив для пользователей;
- `TaleBranch-0.1.0-beta.1-portable.exe` — отдельный исполняемый файл;
- `TaleBranch-0.1.0-beta.1-SHA256.txt` — контрольные суммы.

Не прикреплять `TaleBranch-data`, личные династии, Access-базу, тестовые папки, старую альфу и установщик 2026 года из прежней сборки. В кандидат установщик не входит.

## Репозиторий и публикация

Текущий публичный выпуск: [v0.1.0-alpha.1](https://github.com/UerhaU/TaleBranch/releases/tag/v0.1.0-alpha.1). Его не заменять. Перед новым выпуском проверить состав коммита, исключение локальных данных и успешные CI-проверки.

После ручной проверки перенести проверенные изменения в репозиторий, поставить новый тег на соответствующий коммит и создать отдельный GitHub Release с включённым **Pre-release**. До фактической публикации README и заметки сохраняют формулировку «кандидат»; после публикации обновить статус и ссылки на реальные файлы. Исходные игровые иконки не входят в Git; состав и условия распространения полного набора должны быть учтены в опубликованном пакете и `THIRD_PARTY_NOTICES.md`.
