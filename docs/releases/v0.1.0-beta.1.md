# TaleBranch v0.1.0-beta.1 — Первая бета / First beta

**Черновик описания: релиз ещё не опубликован.**

## Русский

Первая бета TaleBranch для тестирования семейных древ и историй персонажей. Главное отличие от публичной альфы: теперь есть portable-приложение Windows x64. Оно запускается отдельным окном, содержит интерфейс внутри `.exe` и работает без браузера, Node.js и любого HTTP-сервера, включая локальный.

### Как запустить

Скачайте `TaleBranch-0.1.0-beta.1-portable.zip`, распакуйте в доступную для записи папку и запустите `.exe`. Системный Microsoft Edge WebView2 Runtime должен быть установлен. Файлы **Source code** предназначены для разработки.

Династии хранятся в выбранных вами местах. При создании приложение само добавляет папку династии и `dynasty.json`; пустое место назначения не требуется. Настройки находятся в `TaleBranch-data` рядом с программой.

### Что нового

- Прямая работа с папками через нативную часть Tauri, без браузерных подтверждений доступа.
- Игровые справочники, фото при создании карточки, этапы жизни, породы и обязательные хозяева питомцев.
- Полупрозрачные личные связи с метками, отдельные фильтры родства и отношений.
- Корзина с восстановлением и безвозвратным удалением, удаление династии, защита от возврата удалённых данных через историю отмены.
- Улучшенные переводы, обработка ошибок сохранения и защита от перезаписи изменённого файла.

### Переход с альфы и ограничения

Сохраните браузерную династию в папку либо экспортируйте `.dynasty-tree`, затем откройте папку или импортируйте файл в portable. Исходные данные не удаляются. Для тестирования используйте отдельную копию: автоматических резервных копий пока нет.

Игровой каталог содержит русские названия; коми-пермяцкий интерфейс переведён частично. SQLite, отдельные медиафайлы и автоматическое обновление не реализованы. Это тестовый **pre-release**, без цифровой подписи и установщика. Ошибки можно сообщать через GitHub Issues с версией программы и шагами воспроизведения.

## English

The first TaleBranch beta candidate includes a Windows x64 portable app. It opens its own desktop window and needs no external browser, Node.js or HTTP server. Download the attached portable ZIP, extract it into a writable folder and run the executable. Microsoft Edge WebView2 Runtime is required.

Dynasties stay in user-selected locations. The app creates a named folder with `dynasty.json`, including photos, and saves directly through Tauri's native backend. Settings live in `TaleBranch-data` beside the executable.

Changes include game catalogs, profile photos during creation, life stages, pet breeds and required owners, translucent personal connections, independent graph filters, trash restoration and permanent deletion, improved translations and safer saving.

To migrate browser-only data, save it to a folder or export `.dynasty-tree` from the old web app, then open or import it in the portable app. Keep separate test copies; automatic backups are not implemented. Game catalog names remain Russian and Komi-Permyak UI coverage is partial. SQLite, separate media files, automatic updates, an installer and a digital signature are not included.

This is intended as a **pre-release**, not a stable release. Please report issues with the version and reproduction steps. TaleBranch is an independent unofficial project, not affiliated with Electronic Arts or Maxis.
