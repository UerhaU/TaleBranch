# TaleBranch v0.1.0-beta.1 — Первая бета / First beta

## Русский

Первая бета TaleBranch для тестирования семейных древ и историй персонажей. Главное отличие от публичной альфы: теперь есть portable-приложение Windows x64, которое запускается отдельным окном.

### Как запустить

Скачайте `TaleBranch-0.1.0-beta.1-portable.zip`, распакуйте в доступную для записи папку и запустите `.exe`. Системный Microsoft Edge WebView2 Runtime должен быть установлен. Файлы **Source code** предназначены для разработки.

Династии хранятся в выбранных вами местах. При создании приложение само добавляет папку династии и `dynasty.json`; пустое место назначения не требуется. Настройки находятся в `TaleBranch-data` рядом с программой.

### Что нового

- Прямая работа с папками через нативную часть Tauri, без браузерных подтверждений доступа.
- Начальный экран без автоматической формы создания; восстановление последней открытой династии при запуске.
- Игровые справочники, фото при создании карточки, этапы жизни, породы и обязательные хозяева питомцев.
- Игровые списки на выбранном языке: официальная локализация для семи языков и авторские названия для сербского и коми-пермяцкого.
- Поиск участников связи по имени, фамилии и псевдонимам; обмен местами родителя и ребёнка.
- Полупрозрачные личные связи с метками, отдельные фильтры родства и отношений.
- Корзина с восстановлением и безвозвратным удалением, удаление всей папки династии после подтверждения, защита от возврата удалённых данных через историю отмены.
- Улучшенные переводы, обработка ошибок сохранения и защита от перезаписи изменённого файла.

### Переход с альфы и ограничения

Сохраните браузерную династию в папку либо экспортируйте `.dynasty-tree`, затем откройте папку или импортируйте файл в portable. Исходные данные не удаляются. Для тестирования используйте отдельную копию: автоматических резервных копий пока нет.

Полные описания и уровни карьер на сербском и коми-пермяцком пока не переведены; породы на этих двух языках используют английские названия. Авторские переводы нуждаются в вычитке носителями. SQLite, отдельные медиафайлы и автоматическое обновление не реализованы. Это тестовый **pre-release**, без цифровой подписи и установщика. Ошибки можно сообщать через GitHub Issues с версией программы и шагами воспроизведения.

## English

The first TaleBranch beta includes a Windows x64 portable app with its own desktop window. Download the attached portable ZIP, extract it into a writable folder and run the executable. Microsoft Edge WebView2 Runtime is required.

Dynasties stay in user-selected locations. The app creates a named folder with `dynasty.json`, including photos, and saves directly through Tauri's native backend. Settings live in `TaleBranch-data` beside the executable.

Changes include a welcome screen without an automatic creation dialog, reopening the last dynasty, game catalogs following the selected language, profile photos during creation, life stages, pet breeds and required owners, searchable relationship selectors with a parent–child swap button, translucent personal connections, independent graph filters, trash restoration and permanent deletion, entire dynasty folder deletion after confirmation, improved translations and safer saving.

To migrate browser-only data, save it to a folder or export `.dynasty-tree` from the old web app, then open or import it in the portable app. Keep separate test copies; automatic backups are not implemented. Catalogs use official game names in seven languages and authored names in Serbian and Komi-Permyak. Full descriptions and career levels are not yet translated into these two languages, and breeds use English names; authored translations need native-speaker review. SQLite, separate media files, automatic updates, an installer and a digital signature are not included.

This is intended as a **pre-release**, not a stable release. Please report issues with the version and reproduction steps. TaleBranch is an independent unofficial project, not affiliated with Electronic Arts or Maxis.
