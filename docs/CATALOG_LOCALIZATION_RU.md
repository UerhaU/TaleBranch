# Язык игровых справочников

Названия в списках, выбранных значениях, профилях, категориях и поиске зависят от языка интерфейса. Сохраняются исходные игровые ID; смена языка не записывает перевод в файл династии. Произвольные пользовательские значения, имена, заметки и биографии не переводятся.

## Источники

Официальные строки извлечены из установленной `E:\The Sims 4`: `Strings_*.package` базовой игры, дополнений и Delta. Ключи строк получены из настроек конкретных черт, целей, предпочтений, профессий и других игровых объектов. Тексты разных языков сопоставляются по ключу строки, а не переводятся с русского. Для предпочтений используются короткие нейтральные игровые названия, если они есть, чтобы название не зависело от выбранной оценки «нравится / не нравится».

В приложении включены только строки нужных записей: полные игровые таблицы остаются в игнорируемой папке `local-data/catalog-localization`. Официальный источник всегда имеет приоритет над авторским вариантом.

| Покрытие | Источник |
| --- | --- |
| Русский, английский, немецкий, французский, испанский, португальский, упрощённый китайский | 1397 названий из игры для каждого языка, включая породы; доступные описания, ветки и должности карьер; 92 названия наборов |
| Две дополнительные причины смерти | Авторские названия: удушье при еде и критическая поломка серворобота; отдельные строки этих названий в игре не найдены |
| Сербский и коми-пермяцкий | Авторские названия всех 1187 записей в запрошенных семи списках: черты, цели, оккультные типы, причины смерти, навыки, предпочтения, карьеры |
| Категории | Официальные названия, когда есть соответствующий игровой ключ; авторские подписи для классификаций самого приложения |

Для сербского и коми-пермяцкого нет языковых пакетов в установленной игре. Авторские формулировки требуют вычитки носителями; это не официальная локализация EA. Полные описания и уровни карьер на этих двух языках пока не переведены: русский текст не подставляется незаметно. Для пород используются международные английские игровые названия; отдельного авторского перевода пород на эти два языка пока нет.

Возраст «Молодой» остаётся отдельным от «Взрослый» во всех языках по требованию владельца, даже если игра называет его Young Adult. Игровые ключи, доступность по возрастам и фотографии не меняются.

## Повторное извлечение

Скрипты читают игру и подготовленные исследования Access, ничего в них не меняют. Потребуются `local-data/access-catalogs/research/merged.json`, локальная игра, Python и Node.js. Зависимость декодирования устанавливается отдельно от приложения:

```powershell
npm install --prefix local-data/catalog-localization/deps --cache .dev-logs/npm-cache --ignore-scripts --no-audit --no-fund @s4tk/models
python scripts/catalog-string-refs.py
node scripts/extract-catalog-locales.cjs "E:/The Sims 4"
node scripts/build-catalog-locales.cjs
node scripts/build-catalog-authored.cjs
```

Авторские словари находятся в `scripts/catalog-authored-terms.tsv` и `scripts/catalog-authored-categories.tsv`. Генератор связывает их с устойчивыми ID, учитывает повторяющиеся дипломы, страхи и оценки предпочтений. Отчёты с отсутствующими строками создаются в `local-data/catalog-localization`.

Проверки: все запрошенные списки на всех девяти языках, приоритет официальных строк, неизменность ID и правил доступности, поиск по переводу и исходному названию, язык категорий и наборов, выбранные значения и прежние записи в карточках. Проверка пустого описания предотвращает ошибочное сопоставление с другой пустой русской строкой из игровых таблиц.
