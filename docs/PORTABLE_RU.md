# TaleBranch — portable для Windows

Версия: 0.1.0-beta.1. Для начала работы запустите `TaleBranch-0.1.0-beta.1-portable.exe` двойным щелчком. Установка, Node.js, Rust, браузер и запуск сервера не нужны. Интерфейс включён в `.exe`. Полная локальная сборка также включает подготовленные игровые иконки; сборка из чистого клона без этого набора показывает стандартные значки.

## Где разместить программу

Сохраните программу в папке, доступной для записи, например `D:\TaleBranch`. При запуске рядом появится `TaleBranch-data` с настройками, списком недавних папок и профилем встроенного окна. Для переноса настроек на другой компьютер переносите `.exe` вместе с этой папкой. Династии хранятся отдельно в местах, которые вы выбрали.

Программа использует установленный системный Microsoft Edge WebView2 Runtime — компонент отображения интерфейса Windows. На компьютере владельца он обнаружен. Если компонента нет на другом компьютере, его необходимо установить отдельно. Внешний браузер для работы не открывается.

## Династии

- Новая династия: укажите название, выберите место сохранения и нажмите «Создать». В выбранном месте появится папка династии с `dynasty.json`, включая карточки, фотографии, связи и корзину. Место может содержать другие файлы; совпадающие названия получают номер.
- Открыть династию: выберите её папку с `dynasty.json` через «Открыть папку династии».
- Для переноса из веб-версии можно открыть ту же папку на диске либо импортировать прежний экспорт `.dynasty-tree`. Данные, оставшиеся только в браузере, сначала сохраните из веб-версии в папку или экспортируйте.
- Программа записывает изменения напрямую в выбранный файл. Браузерных подтверждений доступа к файлам нет. При создании или открытии папки всё равно используется обычное окно выбора Windows.
- Экспорт династии и PNG предлагают обычное окно «Сохранить как».

Перед закрытием программа завершает сохранение. Если запись не удалась, окно остаётся открытым, чтобы можно было повторить сохранение или экспортировать данные. При конфликте с другим открытым экземпляром приложение не заменяет чужие изменения. В папке династии может находиться служебный файл `.talebranch.lock` для согласования записей; он не содержит карточек или фотографий.

## Без сервера

Рабочая сборка читает встроенные ресурсы из `.exe` и общается с системной частью через IPC. Она не запускает Vite, Node.js, HTTP-сервер или прослушивание порта 1420. Команды `npm run dev` и `tauri dev` относятся только к разработке и для использования portable не нужны.

## Проверка сборки

`--self-test` запускает проверку без открытия интерфейса: встроенные ресурсы, создание папки, чтение и запись файла, список недавних и удаление тестового файла. Используется отдельная временная папка внутри `TaleBranch-data`; пользовательские династии не затрагиваются. Результат записывается в `TaleBranch-data/self-test-result.json`.

Это кандидат в первую бету без цифровой подписи. Установщик и публичная публикация не выполнялись. Перед публикацией остаётся ручная проверка настольного сценария: чек-лист прилагается в архиве как `BETA_CHECKLIST_RU.md`.
