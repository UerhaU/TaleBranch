# Свои стили и темы TaleBranch

TaleBranch можно перекрасить и немного переделать своим CSS — как в Obsidian. Это безопасно: подключается только оформление, никакие программы и скрипты не запускаются, а картинки и шрифты из интернета не загружаются.

## Где лежат файлы

**Настольная версия.** Рядом с `TaleBranch.exe` есть папка `TaleBranch-data`. В ней программа сама создаёт две папки:

- `snippets` — **стили**: небольшие файлы `.css`, которые что-то меняют поверх темы (например, делают фото круглыми). Каждый стиль появляется в «Настройки → Оформление → Свои стили» с переключателем. Включённые стили запоминаются.
- `themes` — **темы**: файлы `.css` с полной палитрой. Каждая тема появляется в списке тем рядом со встроенными.

Добавили или изменили файл — нажмите «Обновить список» в настройках. Перезапускать программу не нужно.

Программа читает только файлы `.css`, лежащие прямо в этих двух папках. Вложенные папки, ярлыки и файлы больше 1 МБ пропускаются.

**Браузерная версия.** Папок нет: в «Настройки → Оформление» есть поле «Свой CSS». Всё, что вы туда впишете, применяется сразу и хранится в настройках этого браузера.

## Если вид сломался

Нажмите **Ctrl Shift 0**. Все свои стили и темы выключатся до перезапуска, а вместо своей темы покажется «Обычная». Затем откройте «Настройки → Оформление», выключите стиль, который всё сломал, и нажмите «Включить снова».

## Как устроено оформление

У корня страницы есть два признака:

- `data-theme` — тема: `default` (Обычная), `garden` (Сад), `magic` (Волшебство), `moon` (Луна), `city` (Город), `kingdom` (Королевство) или имя файла вашей темы;
- `data-mode` — режим: `light` (светлый) или `dark` (тёмный).

Ещё есть `data-pattern="off"` (узор поля выключен) и `data-motion="reduce"` («Меньше движения»).

Все цвета, шрифты и радиусы — переменные с приставкой `--tb-`. Достаточно переопределить переменную, и она поменяется везде.

### Переменные

| Переменная | Что это |
|---|---|
| `--tb-canvas` | фон поля древа |
| `--tb-glass` | полупрозрачный фон островков над полем (верхняя строка, док, карта) |
| `--tb-surface` | фон панелей и окон |
| `--tb-surface-2`, `--tb-surface-3` | фон полей ввода, кнопок, плашек; при наведении |
| `--tb-text` | основной текст |
| `--tb-text-muted` | второстепенный текст (подписи, этап жизни) |
| `--tb-text-faint` | совсем бледный текст и значки |
| `--tb-accent`, `--tb-accent-2` | главный цвет темы и второй цвет; кнопка «Добавить» — градиент из них |
| `--tb-on-accent` | текст на главной кнопке |
| `--tb-accent-text` | ссылки и выбранные пункты |
| `--tb-accent-soft` | мягкая подложка выбранного пункта |
| `--tb-pink`, `--tb-pink-soft`, `--tb-wheat-soft`, `--tb-sky-soft`, `--tb-mint-soft` | цветные подложки черт и меток |
| `--tb-danger`, `--tb-on-danger`, `--tb-danger-text`, `--tb-danger-soft` | красные кнопки, текст и подложки удаления и ошибок |
| `--tb-success-text`, `--tb-warning-text` | «Сохранено» и «Сохраняется» |
| `--tb-kin-line` | линии родства на поле |
| `--tb-rel-line` | линии личных отношений |
| `--tb-card-bg`, `--tb-card-muted-bg` | фон карточки персонажа; карточки умершего |
| `--tb-focus` | рамка фокуса при работе с клавиатуры |
| `--tb-border`, `--tb-border-strong` | тонкие линии и рамки |
| `--tb-overlay` | затемнение под окном |
| `--tb-shadow`, `--tb-shadow-soft`, `--tb-shadow-xs`, `--tb-shadow-lift`, `--tb-accent-shadow` | тени |
| `--tb-glow-1`, `--tb-glow-2`, `--tb-glow-3` | цветные пятна света на фоне поля |
| `--tb-dot` | точки на поле |
| `--tb-minimap-mask` | затемнение мини-карты вне видимой части |
| `--tb-font-body` | шрифт основного текста |
| `--tb-font-display` | шрифт заголовков и имён |
| `--tb-display-caps` | `small-caps`, если заголовки капителью |
| `--tb-display-scale` | множитель размера имени на карточке (для широких шрифтов) |
| `--tb-pattern` | узор поля: картинка `url("data:image/svg+xml,…")`, рисуется цветом текста |
| `--tb-card-deco` | значок-украшение на краю карточки, тоже `data:`-картинка |
| `--tb-radius-xs` … `--tb-radius-xl`, `--tb-radius-pill` | скругления |
| `--tb-inspector-width` | ширина правой панели |
| `--tb-p-blue`, `--tb-p-violet`, `--tb-p-rose`, `--tb-p-amber`, `--tb-p-teal`, `--tb-p-sky`, `--tb-p-coral`, `--tb-p-plum` | цвета персонажей |

Шрифты из интернета не загружаются. Можно указать шрифт, установленный в Windows (например, `"Segoe Print"`), или вписать файл шрифта прямо в CSS как `data:`-адрес.

### Части экрана

Эти имена классов не меняются между версиями.

| Класс | Что это |
|---|---|
| `.tb-app` | всё окно программы |
| `.tb-field`, `.tb-canvas` | поле древа |
| `.tb-card` | карточка персонажа на поле; `.is-selected` — выбранная, `.status-dead` / `.status-missing` — умерший / пропавший |
| `.tb-card-name`, `.tb-card-stage` | имя и этап жизни на карточке |
| `.tb-avatar`, `.tb-avatar-ring` | портрет персонажа и его цветной ободок |
| `.tb-pet` | питомец у портрета хозяина |
| `.tb-quick` | быстрые «+» у выбранной карточки |
| `.tb-topbar`, `.tb-top-row` | верхняя строка: династия, поиск, отмена |
| `.tb-add` | кнопка «Добавить» |
| `.tb-dock` | нижний док; `.tb-nav-item` — его кнопки |
| `.tb-map` | островок с масштабом и мини-картой |
| `.tb-inspector`, `.tb-panel` | правая панель персонажа; `.is-editing` — в режиме правки |
| `.tb-panel-cover`, `.tb-panel-head`, `.tb-panel-body` | цветная шапка, заголовок и содержимое панели |
| `.tb-tabs`, `.tb-tab` | вкладки |
| `.tb-chip` | плашка черты или метки |
| `.tb-menu`, `.tb-menu-item` | меню; `.tb-context-menu` — меню правого щелчка |
| `.tb-modal` | любое окно |
| `.tb-island` | любой «островок» над полем |
| `.tb-start` | начальный экран без открытой династии |
| `.toast` | всплывающее сообщение внизу |

## Образцы стилей

Положите каждый в отдельный файл в папке `snippets`, например `round.css`.

**Круглые карточки и фото побольше**

```css
.tb-card {
  border-radius: 24px;
}
.tb-card .tb-avatar {
  --size: 62px !important;
}
```

**Крупные имена**

```css
.tb-card-name {
  font-size: 18px;
}
.tb-panel-head h2 {
  font-size: 28px;
}
```

**Без узора и украшений, строгие линии**

```css
.tb-field::before,
.tb-card::after {
  display: none;
}
:root {
  --tb-kin-line: #888888;
}
```

## Образец своей темы

Файл `themes/ocean.css`. Первая строка-комментарий задаёт название в списке тем и режимы, в которых тема готова. Имя темы в селекторе — это имя файла маленькими буквами (`ocean`).

```css
/* name: Океан; modes: light dark */
[data-theme="ocean"] {
  --tb-font-display: "Segoe UI", sans-serif;
}
[data-theme="ocean"][data-mode="dark"] {
  --tb-canvas: #06141f;
  --tb-glass: #0c2233d6;
  --tb-surface: #0c2233;
  --tb-surface-2: #12304a;
  --tb-surface-3: #1a3f5e;
  --tb-text: #e8f4ff;
  --tb-text-muted: #b5cde0;
  --tb-text-faint: #7f9ab0;
  --tb-accent: #1f6fb2;
  --tb-accent-2: #127a8a;
  --tb-on-accent: #ffffff;
  --tb-accent-text: #8cc8ff;
  --tb-accent-soft: #3a8fe033;
  --tb-card-bg: #0f2a40;
  --tb-kin-line: #8cc8ff;
  --tb-rel-line: #ff9fb8;
}
[data-theme="ocean"][data-mode="light"] {
  --tb-canvas: #eaf4fb;
  --tb-glass: #ffffffd6;
  --tb-surface: #ffffff;
  --tb-surface-2: #e3f0fa;
  --tb-surface-3: #cfe4f5;
  --tb-text: #0b2235;
  --tb-text-muted: #3d5a72;
  --tb-text-faint: #6a8399;
  --tb-accent: #1f6fb2;
  --tb-accent-2: #127a8a;
  --tb-on-accent: #ffffff;
  --tb-accent-text: #165a94;
  --tb-accent-soft: #1f6fb224;
  --tb-card-bg: #ffffff;
  --tb-kin-line: #3d6a8c;
  --tb-rel-line: #c43468;
}
```

Лучше задать все цвета из таблицы: незаданные берутся из тёмной «Обычной» и могут не подойти к светлому режиму. Полные образцы — блоки шести встроенных тем в исходном файле программы `src/styles.css`. Для читаемости выбирайте цвета так, чтобы текст отличался от фона не меньше чем в 4,5 раза по контрасту: встроенные темы это проходят.
