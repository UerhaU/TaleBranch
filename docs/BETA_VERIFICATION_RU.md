## v0.1.0-beta.1

Дата: 17 октября 2026 года. Это отчёт для подготовки выпуска; пользовательская инструкция находится в [PORTABLE_RU.md](PORTABLE_RU.md), изменения — в [CHANGELOG.md](../CHANGELOG.md).

### Автоматические проверки

Для локального portable-кандидата выполнен `npm run build:portable`:

- 233 теста интерфейса и логики приложения пройдены.
- Проверка TypeScript и сборка веб-ресурсов пройдены.
- 8 нативных тестов файлового хранения пройдены.
- Готовый `.exe` прошёл проверку `--self-test` без открытия интерфейса.
- Подтверждены встроенные ресурсы (1188, из них 1185 игровых иконок), чтение и запись файлов, восстановление последней папки и удаление тестовой папки династии. Сервер для запуска не требуется.
- Проверены контрольные суммы `.exe` и ZIP. В архиве нет профиля приложения, пользовательских династий или базы Access.

Эти результаты относятся к проверенному исполняемому файлу. Последующие изменения документации не требуют пересборки `.exe`; перед публикацией следует заново упаковать актуальные документы и проверить контрольную сумму нового архива.

### Ручная проверка

Владелец проверил portable-бету и сообщил: «Я проверила бету. Вроде всё хорошо». Сообщений об оставшихся ошибках в этой проверке не поступило.

Поэлементный протокол не предоставлен. Это сообщение не означает отдельного подтверждения всех пунктов контрольного списка и проверки на других компьютерах.

### Дополнительные сценарии без отдельного ручного подтверждения

Использовать отдельную тестовую династию, не изменяя личные данные.

- [ ] Запуск на другом компьютере Windows x64 и наличие WebView2.
- [ ] Начальный экран без формы создания; создание в непустом месте, без изменения соседних файлов.
- [ ] Карточка с фотографией и кадрированием; питомец с обязательным хозяином.
- [ ] Поиск участников связи, обмен родителя и ребёнка; метки и фильтры линий.
- [ ] Сохранение и автоматическое открытие последней династии после перезапуска.
- [ ] Экспорт `.dynasty-tree` и PNG; импорт в отдельное место.
- [ ] Корзина, восстановление и безвозвратное удаление; удалённые данные не возвращаются после перезапуска или отмены действий.
- [ ] Подтверждённое удаление целой тестовой папки династии; соседние файлы сохранены.
- [ ] Вычитка авторских сербских и коми-пермяцких названий носителями языка.

### Диагностика готового файла

Аргумент `--self-test` запускает проверку без окна и использует отдельную временную папку внутри `TaleBranch-data`. Результат записывается в `TaleBranch-data/self-test-result.json`. Личные династии не используются. Эта проверка не заменяет работу с интерфейсом.
