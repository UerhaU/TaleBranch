# Сторонние компоненты

Прямые runtime-зависимости:

- React и React DOM — MIT;
- XYFlow / React Flow — MIT;
- Lucide — ISC;
- html-to-image — MIT;
- Tauri — Apache-2.0 / MIT.
- @tauri-apps/api — Apache-2.0 / MIT (сохранение перед закрытием настольного окна).
- NSIS — zlib/libpng;
- Microsoft Edge WebView2 Runtime — распространяется в составе офлайн-установщика на условиях Microsoft.

Интерфейсные иллюстрации, игровые логотипы и закрытые ассеты не включены. Перед публичным релизом список следует автоматически сверить с lock-файлами.
