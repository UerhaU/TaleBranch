# Сторонние компоненты

Прямые runtime-зависимости:

- React и React DOM — MIT;
- XYFlow / React Flow — MIT;
- Lucide — ISC;
- html-to-image — MIT;
- lz-string — MIT (сжатие локально сохраняемых данных без потери фотографий и текста);
- Tauri — Apache-2.0 / MIT.
- tauri-plugin-dialog / rfd — Apache-2.0 / MIT (системные окна выбора папок и сохранения файлов).
- sha2, tempfile, base64 — Apache-2.0 / MIT (контроль целостности, атомарная запись и экспорт PNG).
- @tauri-apps/api — Apache-2.0 / MIT (сохранение перед закрытием настольного окна).
- NSIS — zlib/libpng;
- Microsoft Edge WebView2 Runtime — системный компонент на условиях Microsoft. Portable использует установленный runtime; в будущий офлайн-установщик он может включаться отдельно.

Portable-сборка включает игровые иконки и строки локализации The Sims 4.
